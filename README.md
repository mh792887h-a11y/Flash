# Flash Note 4 - فلاش

تطبيق أندرويد أصلي (Android Native) عالي الأداء لتشغيل كشاف الكاميرا الخلفي مع تكرار صوتيات مضحكة بأعلى صوت، مخصص لهاتف **Samsung Galaxy Note 4** ومتوافق مع جميع أجهزة أندرويد من نظام **Android 6.0 Marshmallow (API 23)** وحتى الإصدارات الحديثة **Android 14+ / 15+**.

---

## 📱 مميزات التطبيق

1. **واجهة شديدة البساطة والأناقة:**
   - خلفية سوداء نقية توفر طاقة البطارية وتمنح تركيزاً كاملاً.
   - كلمة «فلاش» باللون الأبيض.
   - زر دائري كبير في منتصف الشاشة للتشغيل والإيقاف بنقرة واحدة، مع رمز كشاف وتأثير توهج ذهبي مشرق عند التشغيل.
2. **تشغيل الفلاش الخلفي الحقيقي:**
   - استخدام واجهة `CameraManager` الرسمية (`setTorchMode`) لاكتشاف وتشغيل فلاش الكاميرا الخلفية.
3. **مجموعة الأصوات المضحكة (12 مقطعاً مدمجة):**
   - تشغيل المقاطع الصوتية المضحكة المرفقة بالتتالي والتكرار المستمر بأعلى صوت ما دام الفلاش يعمل.
   - إيقاف الصوت فوراً وتحرير الموارد بمجرد إطفاء الفلاش.
4. **العمل في الخلفية وعند قفل الشاشة (Foreground Service + WakeLock):**
   - يستمر الفلاش والصوت في العمل عند الضغط على زر Home، الانتقال لتطبيق آخر، أو قفل الشاشة بزر الطاقة.
   - إشعار دائم واضح في شريط الإشعارات يحتوي على زر سريع: «إطفاء الفلاش».
5. **اختصار الأزرار العلوية (Quick Settings Tile):**
   - يدعم زر اختصار سريع في لوحة الضبط السريع بالأعلى بجانب أزرار الواي فاي والبيانات، لتشغيل وإطفاء الفلاش مباشرة دون فتح التطبيق.

## 🛠️ متطلبات البناء (Build Requirements)

- **Android Studio:** Hedgehog / Iguana / Ladybug أو أحدث.
- **Gradle:** 8.x+
- **Android SDK:**
  - `minSdkVersion`: 23 (Android 6.0 Marshmallow - يدعم Note 4 بشكل أصلي).
  - `targetSdkVersion`: 36 (متوافق مع أحدث معايير الأمان وخدمات الخلفية).
  - `Java Version`: 11+

## 🎵 إضافة أو تغيير الملفات الصوتية

الملفات الصوتية مدمجة بالفعل داخل المسار التالي:
`app/src/main/res/raw/`

إذا أردت استبدال ملف الصوت أو إضافة ملف جديد باسم `funny_sound.mp3`:
1. انسخ ملف الصوت بصيغة `mp3` أو `m4a`.
2. تأكد أن الاسم بأحرف إنجليزية صغيرة وأرقام وشرطة سفلية فقط: `funny_sound.mp3`.
3. ضعه في المجلد: `app/src/main/res/raw/funny_sound.mp3`.
4. يمكن الوصول إليه تلقائياً في الكود من خلال: `R.raw.funny_sound`.

## 🚀 طريقة فتح المشروع وبناء ملف APK

### 1. فتح المشروع في Android Studio:
1. افتح برنامج **Android Studio**.
2. اختر **Open** ثم حدد مجلد المشروع.
3. انتظر حتى ينتهي مزامنة Gradle بنجاح.

### 2. بناء ملف APK عبر سطر الأوامر:
```bash
gradle assembleDebug
```
أو على نظام ويندوز / لينكس عبر Gradle:
```bash
gradle :app:assembleRelease
```
سيتم توليد ملف APK داخل المجلد:
`app/build/outputs/apk/debug/app-debug.apk`

## 📲 طريقة تثبيت التطبيق على هاتف Samsung Galaxy Note 4

1. انقل ملف `app-debug.apk` إلى ذاكرة الهاتف عبر كابل USB أو البلوتوث أو التنزيل المباشر.
2. في هاتف Galaxy Note 4: توجّه إلى **الضبط (Settings)** > **الحماية (Security)** > فعّل خيار **مصادر غير معروفة (Unknown Sources)**.
3. افتح تطبيق «ملفاتي» (My Files) واضغط على ملف `app-debug.apk` ثم اضغط **تثبيت (Install)**.
4. افتح التطبيق واضغط على زر الكشاف؛ سيطلب منك إذن الكاميرا أول مرة لتشغيل ضوء الفلاش.

## 🔒 الأذونات المستخدمة وسبب الحاجة إليها

- `android.permission.CAMERA`: مطلوب للتحكم بضوء فلاش الكاميرا الخلفية عبر `CameraManager`.
- `android.permission.FLASHLIGHT`: إذن نظام للتحكم في الكشاف.
- `android.permission.WAKE_LOCK`: للحفاظ على استمرار عمل المعالج وتشغيل الفلاش والصوت عند قفل الشاشة بزر التشغيل.
- `android.permission.FOREGROUND_SERVICE`: لتشغيل الخدمة الأمامية التي تمنع النظام من إيقاف الصوت والفلاش عند الخروج من التطبيق.
- `android.permission.FOREGROUND_SERVICE_CAMERA`: متطلب إلزامي في إصدارات أندرويد الحديثة للخدمات الأمامية المتعلقة بالكاميرا.
- `android.permission.FOREGROUND_SERVICE_MEDIA_PLAYBACK`: متطلب إلزامي للخدمات الأمامية التي تشغل وسائط صوتية.
- `android.permission.POST_NOTIFICATIONS`: لإظهار إشعار التحكم السريع في أندرويد 13 فما فوق.
- `android.permission.VIBRATE`: لإعطاء استجابة لمسية (اهتزاز خفيف) عند الضغط على الزر.

## ⚠️ القيود وملاحظات التشغيل

- **إيقاف النظام القسري:** إذا قام المستخدم بإجبار إيقاف التطبيق (Force Stop) من إعدادات النظام، أو نَفِدت بطارية الجهاز تماماً، سيتوقف الفلاش تلقائياً لحماية العتاد.
- **انشغال الكاميرا:** إذا كان هناك تطبيق آخر يستخدم الكاميرا في نفس اللحظة، سيتم إشعار المستخدم عبر واجهة التطبيق.
- **اختصار الأزرار العلوية (Quick Settings Tile):** ميزة أزرار الضبط السريع العلوية الرسمية متوفرة ابتداءً من Android 7.0+، وفي هواتف Android 6.0 Note 4 يتوفر التحكم السريع المباشر والدائم عبر شريط الإشعارات المنسدل.
